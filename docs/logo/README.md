# Logo

The DeskWatch logo, the same status ring as the tab icon in `bridge/icons/`.

| File | Use |
|---|---|
| `deskwatch-logo.svg` | The logo as a vector, for the README and anywhere it must scale. |
| `deskwatch-logo-512.png` | 512x512 PNG with a transparent corner, for an avatar or a profile picture. |
| `social-preview.png` | 1280x640, the image GitHub shows when the repository link is shared. Upload it under the repository's Settings, General, Social preview. |
